! Sentinel - bundled starter blocklist
!
! WHAT THIS IS
! A small, hand-picked list of advertising and tracking host names used to
! exercise the filtering engine and to give a fresh install something to block.
! It is NOT a complete ad blocklist and it is not derived from any list that has
! licence terms attached to it. Every entry below is a host name that is
! published by the operator of that service as its own advertising or analytics
! endpoint, or a well-known ad-serving domain.
!
! HOW TO EXTEND IT
! Either edit this file (app/src/main/assets/blocklist/test-blocklist.txt) or
! add hosts through the app's Rules screen. User rules always win over this file.
!
! SYNTAX SUPPORTED BY THE PARSER
!   ||example.com^     block example.com and all subdomains
!   0.0.0.0 example.com   hosts-file form
!   example.com        bare host name
!   @@||example.com^   exception (allow) rule
!   ! comment  /  # comment  /  [section header]
!
! NOT SUPPORTED (counted and reported, never silently accepted)
!   cosmetic rules (##.ad-banner), $-modifiers, paths, wildcards, regex.
!   Those belong to browser-level blockers; this app filters DNS names only.
